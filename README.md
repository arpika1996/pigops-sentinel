# PigOps Sentinel

An autonomous farm-monitoring agent built for the
**All Things Agentic Hackathon** (Google / Devpost) — track *The Taskmaster*.

It watches live pig-farm data in Firestore on its own schedule, decides what
matters, creates tasks for the right person, and escalates when they are
ignored. Built on **Google ADK** + **Gemini on Vertex AI** + **Cloud Run**.
