PigOps Sentinel — how one run works

An autonomous farm-monitoring agent on top of PigOps (Firestore). No user request triggers it: Cloud Scheduler wakes it every 15 minutes.

Cloud Run · sentinel-agentFastAPI · one run per request · concurrency 1 · runs as sentinel-agent@ (aiplatform.user, datastore.user)

1
Scan deterministic
rules over the farm snapshot → candidates: MORTALITY_SPIKE · DEADLINE_RISK · SILENT_ROOM · VALVE_INSTABILITY. Already-handled candidates are skipped (open Sentinel task, notified deadline, identical NOISE/WATCH verdict inside the cooldown) — quiet runs cost 0 tokens.
2
Investigate Google ADK · Gemini 3.5 Flash on Vertex AI
one LlmAgent, one session per run; the model chooses its own look-ups: get_structure · get_room_stats · get_mortality_history · get_farm_mortality_overview · get_open_tasks · get_valve_log — names in, names out, never raw IDs.
3
Decide structured output
NOISE · WATCH · ACT (+ severity, English reasoning citing the numbers it retrieved).
4
Act guardrails in code
create_task for the farm's responsible person (dedup window, per-run cap, assignee fallback noted) · send_notification (FCM) — DEADLINE_RISK notifies the assignee + farm manager instead of duplicating the task.
5
Follow up every run, even quiet ones
its own tasks: open past 24 h → severity up + manager nudged + escalation logged; closed → outcome logged (the seed of learning).

Firestorethe PigOps data model, field-for-field

  • telepek/{farm}/hizlaldak/{barn}/termek/{room}/szelepek
  • …/elhullasok mortality · …/feladatok tasks + work log
  • naplo/…/modositasok valve log · users, jogosultsagok
  • writes (the agent's footprint)
  • …/feladatok new tasks — exactly the shape the PigOps app reads, plus source: sentinel markers
  • sentinelLog/{id} the decision log — observation · contextGathered · reasoning · decision · severity · actionTaken · escalation … one document per outcome, NOISE included
  • sentinelRuns/{runId} live phase, counters, status of every run
Demo dataset: the app's own "PigOps" demo farm (A-Telep / B-Telep, 12 rooms, 192 valves, 21 days of history, 6 planted anomalies + 3 decoys) — python -m sentinel.seed --reset. No real farm data.
